# Devcat Store

Devcat Store is a friendly place to discover apps made by DevCat. Learn what each app does, compare available downloads, and find privacy and release information before installing.

## What you’ll find

- App pages with screenshots, features, supported platforms, and requirements
- Android APKs and Windows installers, with alternate downloads and older versions when available
- Privacy policies, permissions, release notes, and file checksums
- Links to Google Play, F-Droid, and source code when available

## Featured app

**[Quick Insure](https://github.com/DevCat-exe/Quick-Insure)** is an offline-first insurance calculator for Android and Windows. It supports motor insurance, fire insurance, and overseas medical coverage.
